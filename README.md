# Comparative Capital Structure: Telstra and Telecom Peers

A write-up of Part B of a corporate finance advisory report on Telstra Group Limited (ASX: TLS),
covering peer selection, the data rules used to make the comparison valid, and how Telstra's leverage
compares to TPG Telecom, Optus and Aussie Broadband over FY2019 to FY2025.

Written by Evelyn Lieu. The page covers only my own section; the submitted group report is not
reproduced and my co-authors' sections are not included.

## Publishing this to GitHub Pages

1. Create a new **public** repo under your account, e.g. `telstra-capital-structure`.
2. Push these two files to the default branch:

```bash
git init
git add index.html README.md figure3.png figure4.png figure6.png figure7.png
git commit -m "Capital structure comparison write-up"
git branch -M main
git remote add origin https://github.com/evelynlieu1/telstra-capital-structure.git
git push -u origin main
```

3. On GitHub: **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**.
4. After a minute the page is live at
`https://evelynlieu1.github.io/telstra-capital-structure/`.

To preview before pushing, just open `index.html` in a browser.
